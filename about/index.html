About SecurePass

SecurePass is a password generator that runs entirely in your browser. There is no account to create, no server that sees your passwords, and no analytics watching what you generate. The page you are reading is the whole application.

How generation works

  • Randomness comes from the Web Crypto API (crypto.getRandomValues()) — the same cryptographic source browsers use for TLS keys. Math.random() is never used for anything secret.
  • Random values are mapped to characters with rejection sampling, so every character in a pool is equally likely (no modulo bias).
  • When “require one character from each group” is on, the forced characters are shuffled into random positions with a cryptographic shuffle — they never sit in predictable spots.
  • Passphrases draw from the bundled EFF large word list (7,776 words, ~12.9 bits of entropy per word), also via the Web Crypto API.

What the strength meter means

The meter shows an estimated entropy in bits, computed from the password length and the effective character pool (or word-list size for passphrases). It is a way to compare settings — not a guarantee. Real-world security also depends on phishing resistance, password reuse, and whether a password has leaked before. SecurePass does not claim to make you “unhackable”; a password manager plus unique passwords per site remains the best practical advice.

Technology

Built with Astro (static-first pages), React islands (only the interactive generator hydrates), TypeScript, Tailwind CSS, and Lucide icons. The generation logic is deliberately separated from the UI in src/lib/ so it stays small, testable, and easy to audit.
